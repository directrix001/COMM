How this will work

Each SOP version is embedded and stored. When a new version is uploaded, the tool retrieves the matching prior sections (RAG), diffs them, and asks gpt-4o-mini to summarize what materially changed, why it matters, and how risky it is — instead of a raw line-by-line diff. Everything below is a mock of that output; the retrieval + generation pipeline plugs in later.
